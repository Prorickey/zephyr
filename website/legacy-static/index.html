01 — Project Overview

Zephyr is a two-person exploration into what happens when a humble electric scooter learns to think for itself. Summon it from across campus, ride it wherever you like, and let it quietly return itself to the nearest charging dock.

Built from the ground up — frame, drivetrain, perception stack, and companion app — Zephyr is equal parts robotics testbed and daily commuter. This page is a living document of the project; the copy below is placeholder while we write up the real results.
